Safeer Control nikoli ne omogoča poljubnih lupinskih ukazov ali oddaljenega roota. Vsaka operacija se preveri na strani krmilnika IN na strani naprave.

🔒

V0.8.1 PIN Bootstrap & TLS Pinning

Vzpostavitev zaupanja z enkratnim 6-mestnim PIN-om, izmenjavo nonces in obojestransko potrditvijo transkripta. Izpeljava 256-bitnega sejnega ključa in kriptografsko pripenjanje SHA-256 certifikata preprečuje MITM napade.

🔑

Ed25519 OTA Trust Root & Anti-Downgrade

Posodobitve programske opreme zahtevajo digitalni podpis z uradnim Ed25519 ključem izdaje. Vgrajena monotona zaščita preprečuje napade z znižanjem različice (Anti-Downgrade).

🛡️

Strogo Omejen Nabor Zmogljivosti

Dostopne so izključno 3 tipizirane operacije: settings.read, app.force_stop in app.cache_maintenance. Vsi poskusi podtikanja ukazov ali shell sintakse so fail-closed zavrnjeni.

🐕

Nadzornik (Watchdog) & Samodejno Okrevanje

Nadzorni proces safeer-companion-watchdog.sh neprekinjeno spremlja delovanje demona, preprečuje zanke sesutja (crash-loop karantena) in ob prekinitvi proces obnovi v manj kot 2 sekundah.

📊

Pasiven FPS Performance Observer

Neodvisna diagnostična komponenta meri hitrost osveževanja (60/120Hz), zakasnitve izrisa (p50, p95, p99) in zatikanje (Jank %) neposredno prek standardnih Android orodij brez vdiranja v varovano jedro.

🌐

Safeer Browser Integracija

Vnaprej odobren mobilni in TV brskalnik z vgrajenim Safeer Threat Shieldom, 0-ad blokiranjem ter varnim upravljanjem predpomnilnika in procesov.

Hitra & Enostavna Namestitev

Izberite Svojo Platformo

Safeer Control vozlišče teče na vašem računalniku ali strežniku, Safeer Companion pa na vaših Android napravah ali TV-ju.

1
Enovrstična samodejna namestitev (Priporočeno)
Skript samodejno pripravi izolirano okolje v ~/.local/share/safeer-control in ustvari bližnjico safeer-control.
curl -sSL https://raw.githubusercontent.com/memelandfaner/safeer-control/main/scripts/install.sh | bash
2
Ali ročna namestitev iz Git repozitorija
Če želite kodo pregledati ali razvijati lokalno:
git clone https://github.com/memelandfaner/safeer-control.git && cd safeer-control && pip install -r requirements.txt
3
Zagon spletnega strežnika in nadzorne plošče
Strežnik se zažene na vratih 8990 z vgrajenim spletnim vmesnikom in WebSocket telemetrijo:
safeer-control serve
1
Aktivacija Shizuku (Brez Roota)
Namestite Shizuku iz Google Play ali GitHub. Aktivirajte ga prek možnosti »Brezžično odpravljanje napak« (Wireless Debugging) v nastavitvah razvijalca.
2
Namestitev Safeer Companion APK
Zgradite ali prenesite uradno podpisani APK paket:
bash companion/android/build_companion_apk.sh && adb install -r companion/android/build/SafeerCompanion.apk
3
Dodelitev Shizuku dovoljenja & Zagon
Dodelite dovoljenje API v23 ter zaženite foreground storitev:
adb shell pm grant com.safeer.companion moe.shizuku.manager.permission.API_V23 && adb shell am start-foreground-service com.safeer.companion/.SafeerCompanionService
1
Prevod statične ARM64 binarne datoteke
Go program ne potrebuje nobenih zunanjih knjižnic ali Android SDK-ja:
CGO_ENABLED=0 GOOS=linux GOARCH=arm64 go build -ldflags="-s -w" -o /tmp/safeer-companion ./companion/native/main.go
2
Prenos na napravo z varnimi pravicami (0700)
Namestitev v /data/local/tmp prek ADB povezave:
adb push /tmp/safeer-companion /data/local/tmp/safeer-companion && adb shell "chmod 0700 /data/local/tmp/safeer-companion"
3
Zagon v varnem TLS načinu s seznanitvenim PIN-om
Demon samodejno generira samopodpisani TLS certifikat ter 6-mestni PIN za enkratno potrditev:
adb shell "/data/local/tmp/safeer-companion -host=0.0.0.0 -port=8995 -tls -pair -rish-path=/data/local/tmp/rish"
1
Zasebni brskalnik z ničelno telemetrijo
Safeer Browser (com.safeer.mobile.browser) je integriran v Safeer Control ekosistem z vnaprej odobrenimi privilegiji za hitro pavzo, predpomnilnik in FPS analitiko.
2
Enostavno upravljanje predpomnilnika prek CLI
Varno čiščenje začasnih podatkov brez brisanja uporabniških nastavitev:
safeer-control shizuku clear-cache com.safeer.mobile.browser
3
Merjenje hitrosti osveževanja z FpsObserverjem
Preverite, ali brskalnik dosega polnih 60 sličic na sekundo:
safeer-control observer fps --package com.safeer.mobile.browser --duration 3
